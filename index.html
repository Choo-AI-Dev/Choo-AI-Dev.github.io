What I work on

  • Industrial image classification

    Classifiers that find defects in manufacturing images and keep up with line speed.

  • Models that hold up under domain shift

    Ensembles and transfer learning that keep a model accurate when products, lines or imaging conditions change.

  • Specification-aware inspection

    Judging each defect against the customer's own specification, because the same defect can pass for one customer and fail for another.

  • Selective LLM inference

    Cascades that call a language model only for ambiguous or high-risk samples, so cost and latency stay low.

My GitHub is my playground. Whatever I'm working on gets written down and put there, finished or not. These are the ones people can use today.

Screenmit

Side project, Windows · web, 2026

A Windows app that keeps every screenshot for two weeks, then clears them out. I kept losing screenshots to the next copy or to the other computer, so Screenmit saves each one the moment it's taken, notes which app it came from, and syncs through your own Google Drive, so a work PC, a home PC and a phone all see the same list. No server and nothing to install.

Penmit PDF

Side project, web · Windows · Linux · Android, 2026

A free PDF reader for writing on PDFs with a pen on any device. Notes are saved as standard PDF annotations and sync through each person's own Google Drive or GitHub, so there is no server to pay for and nobody else holds your notes.

ReteKey G

Side project, Android, 2026

A Gboard-style Korean keyboard for the Lenovo Xiaoxin Pad Pro 13. Gboard can't switch between Korean and English on a physical keyboard, so I took the open-source ReteKey IME, kept its input engine, and rebuilt the on-screen keyboard.
